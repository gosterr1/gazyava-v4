# ГАЗЯВА — мега-мульти бас-плагин (VST3 для FL Studio)

## Обновить плагин на GitHub
1. В репозитории: **Add file → Upload files**.
2. Перетащи `CMakeLists.txt`, папки `Source` и `Assets` (одноимённые файлы перезапишутся, новые добавятся).
3. **Commit changes** → вкладка **Actions** → дождись зелёной галочки → скачай `Gazyava-Windows`.
4. Закрой FL Studio, замени папку `Gazyava.vst3` в `C:\Program Files\Common Files\VST3\`, запусти FL → Find installed plugins.

## Мяуканье манулов
Клик по коту — случайный настоящий звук: мяу / вопль / шипение. Файлы: `Assets/meow_a.wav` (мяу), `meow_b.wav` (вопль), `meow_c.wav` (шипение).
Можно заменить на свои с теми же именами (WAV) и закоммитить.
Если звука не слышно в FL: в окне обёртки плагина (шестерёнка) выключи **Smart disable**.
